# Runtime local — contenu non versionné

Cette arborescence reproduit les principaux volumes utilisés par les workers. Les fichiers réels sont volontairement exclus de Git : articles collectés, logs, référentiels de production, sorties Hot News, données marché et métriques blockchain.

Les `.gitkeep` conservent uniquement la structure des dossiers pour rendre l'architecture visible dans le dépôt public.
